# Icon Assets (PNG)

Semua icon navbar, sidebar, dan logo aplikasi di Astraonyx sekarang menggunakan file gambar **PNG** di folder `public/icons/`.

## Cara Mengganti Icon dengan Milik Sendiri:
Anda dapat langsung menimpa (replace) file gambar PNG di folder ini dengan file PNG Anda sendiri kapan saja:
