The vault at `.skills/ai-design-vault` serves as the project's permanent design reference vault:
- **Map of Content**: Consult `.skills/ai-design-vault/obsidian/README.md` and `obsidian/workflows/ai-agent-guide.md`.
- **Stack-Agnostic Judgement**: Apply the aesthetic and engineering principles to any UI work (layout, typography, color, spacing, motion) without restructuring the app.
- **Design Rules**:
  - **Layout & Spacing**: 3-tier token architecture, fluid scaling, generous section breathing room, clean component hierarchy.
  - **Typography**: Editorial scale, proper leading (>= 1.1 when clipping overflow), pair text alignment with flex alignment.

  - **Motion**: Spring-based physics, single binding contract, discrete CSS transitions only for hover/focus states.
- **Contradiction Alert**: Proactively inform the user whenever an asked change directly violates these vault design principles.
